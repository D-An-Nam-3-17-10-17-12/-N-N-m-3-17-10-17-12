 BÀI 1: TÌM ĐƯỜNG ĐI NGẮN NHẤT

1. Mô tả
Tìm đường đi ngắn nhất để xe di chuyển và ghé thăm các điểm được yêu cầu trong kho.

2. Thuật toán
- BFS: Tìm đường đi ngắn nhất.
- DP Bitmask: Tìm thứ tự ghé thăm tối ưu.
3. Ngôn ngữ
C#.

 4. Cách chạy
Mở file .csproj bằng Visual Studio và nhấn Ctrl + F5.

 5. Kiểm thử
Đã kiểm thử đường đi hợp lệ, không có đường đi và dữ liệu không hợp lệ.
