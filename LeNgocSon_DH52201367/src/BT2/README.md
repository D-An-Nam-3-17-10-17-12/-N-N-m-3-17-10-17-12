# Hướng dẫn chạy Bài 2 – Nhập/xuất kho theo FIFO

Mã nguồn được viết bằng ngôn ngữ **C++** và gói gọn trong một file `solution.cpp` duy nhất.

1. Mở file `solution.cpp` bằng Visual Studio Code.
2. Biên dịch và chạy chương trình (Nhấn `Ctrl + F5`).
3. Nhập Input vào cửa sổ Terminal vừa xuất hiện rồi nhấn Enter, kết quả sẽ xuất hiện trên cửa sổ của Terminal.
