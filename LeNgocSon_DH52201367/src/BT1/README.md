Sử dụng IDE (Visual Studio)
Bước 1: Mở trực tiếp file solution.cpp bằng IDE hỗ trợ C++.
Bước 2: Bấm nút Build and Run (Hoặc phím tắt Ctrl + F5 đối với Visual Studio).
Bước 3: Khi cửa sổ Terminal (màn hình console đen) hiện lên, hãy nhập toàn bộ dữ liệu Test Case vào cửa sổ và nhấn Enter. Kết quả sẽ được in ra ngay lập tức.
